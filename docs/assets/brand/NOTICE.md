These files are the logo:

- everything in this directory (`docs/assets/brand/`);
- `docs/assets/molebridge-banner.svg`;
- the panel's icons in `panel/static/`: `favicon.svg`, `favicon-32.png`,

those files stay all rights reserved there too. If you distribute a modified
